# GenAI Project

## Overview

This repository contains Generative AI laboratory experiments implemented using Python, Google Colab, Hugging Face Transformers, and Large Language Models. The experiments demonstrate various applications of foundation models, including text generation, prompt engineering, chatbots, summarization, sentiment analysis, Retrieval-Augmented Generation (RAG), and AI-assisted code generation.

---

## Experiments

| Ex. No. | Experiment 
|:-------:|------------|
| 1 | Text Generation Using Pre-Trained Foundation Models 
| 2 | Prompt Engineering Techniques For Content Generation, Reasoning And Task Automation
| 3 | Conversational AI Chatbot Using Transformer-Based Language Models 
| 4 | Text Summarization And Question-Answering System Using Large Language Models 
| 5 | Sentiment Analysis And Document Classification Using Foundation Models 
| 6 | Retrieval-Augmented Generation (RAG) System Using Vector Databases 
| 7 | AI-Powered Code Generation And Debugging Assistant

## Objective

The objective of this repository is to implement and understand the concepts of Generative AI through practical experiments using transformer-based models and foundation models. Each notebook demonstrates a specific Generative AI application and its implementation using modern AI frameworks.
